# B 站文字播放器

一个 Chrome 和 Microsoft Edge 浏览器扩展。在独立标签页中搜索 B 站视频、浏览自己的收藏夹、连续收听或下载视频音轨。界面以文字列表为主。灵感来自 Listen 1。 [Listen 1](https://listen1.github.io/listen1/)

## 安装

使用 Chromium 116 或更新版本的 Chrome 或 Edge。

1. 下载并解压 `qzz-bili-word-page-v1.1.0.zip`，也可以直接使用仓库源码。 [v1.1.0 发布页](https://github.com/Mai-Mu/qzz-bili-word-page/releases/tag/v1.1.0)
2. 在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
4. 点击工具栏中的「B 站文字播放器」打开独立播放页。再次点击会切回已有播放页。

已通过开发者模式安装过的用户，可以用新版文件覆盖原来的扩展目录，再在扩展管理页点「重新加载」，以保留播放进度和队列。

## 使用

- 用同一浏览器配置登录 B 站，回到播放器点右上角的刷新按钮，即可**查看自己创建的收藏夹**，包括默认和私密收藏夹。右下角的搜索框只查找当前收藏夹里的视频。 [B 站首页](https://www.bilibili.com/)
- 用顶部搜索框**搜索全站视频**。收藏夹和全站搜索的列表每页最多显示 100 条。翻页、筛选和重新搜索时，当前音频继续播放。点播新条目时，从那条开始连播。
- 点 UP 主的名字，按播放量浏览该 UP 主的投稿。
- 播放模式按钮在**顺序、随机和单曲循环**之间切换。随机模式打乱已加载的视频，后续分页自动接入队列。多 P 视频按分 P 顺序播放，单曲循环重复当前一 P。连播时会跳过失效稿件和缺少独立音轨的条目。
- 播放器自动选择浏览器可播放的**最高音质**。播放栏显示实际音轨档位，音频开始播放后加载当前视频的封面。点封面并确认即可在新标签页打开原视频。
- 当前视频有可播放的分 P 时，点播放栏时间轴右侧的下载图标，可以把这一 P 单独保存为 **M4A 音频**。面板默认选最高可用音质，可修改歌曲名和歌手，默认将歌曲信息和封面嵌入文件，也可勾选「同时另存封面」。多 P 视频默认以当前分 P 标题作为歌曲名。
- 音频以「歌曲名_歌手.m4a」命名，单个音频的处理上限为 256 MB。嵌入失败时，可以重试或选择「保存原音频」。
- 切到其他标签页可**继续收听**。关闭播放页后，再次打开可恢复队列和进度，点播放继续。Edge 和 Windows 的媒体控制中心可显示当前视频的标题、UP 主和封面，并提供播放控制。在 Edge 中，来源栏可能显示扩展页地址。

如果 B 站拦截了新浏览器配置里的搜索，先打开一次 B 站首页并等待页面加载，再回来重试。 [B 站首页](https://www.bilibili.com/)

## 数据和权限

收藏夹请求复用浏览器现有的 B 站登录状态，登录凭据由浏览器处理。队列、进度和播放设置保存在本机。扩展仅为自身向 B 站接口及媒体服务器发起的相应请求设置 `Referer`。

下载和标签写入都在浏览器本地完成，保留音频的原编码。扩展使用 `downloads` 把文件交给 Chrome 或 Edge 下载管理器，并使用 `offscreen` 处理音频和封面。下载流程参考同作者的 BiliAudio，复用了其 M4A 标签写入代码。 [BiliAudio 音频下载器](https://github.com/Mai-Mu/qzz-bili-music-downloader)

## 项目结构

扩展使用 Manifest V3 和原生 HTML、CSS、JavaScript，解压后即可加载。

| 路径 | 用途 |
| --- | --- |
| `manifest.json` | 扩展入口、权限和图标声明 |
| `background.js` | 打开和切换播放页，设置媒体请求规则，接收下载请求 |
| `index.html`、`src/styles.css` | 播放页和界面样式 |
| `src/app.js` | 收藏夹、搜索、分页与播放控件接线 |
| `src/bili-api.js` | B 站登录状态、列表及音轨请求 |
| `src/player.js`、`src/media-session.js` | 队列、音频播放、断点续听和浏览器媒体控制 |
| `src/download-dialog.js`、`src/download-jobs.js` | 下载面板和浏览器保存流程 |
| `src/download-offscreen.html`、`src/audio-jobs.js`、`src/audio-metadata.js` | 读取音轨和封面，写入 M4A 标签 |
| `assets/` | 项目标志和扩展图标 |
